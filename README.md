# ورشة الصقر — Landing Page

مشروع React + TypeScript + Tailwind لصفحة هبوط ورشة تصليح سيارات (مشروع تعليمي).

## كيف تشغّله محلياً

```bash
npm install
npm run dev
```

بعدها افتح الرابط يلي بيظهر بالتيرمينال (عادة `http://localhost:5173`).

للنشر على Vercel:

```bash
npm run build
```

وبعدها اربط المستودع (repo) بـ Vercel مباشرة من لوحة التحكم تبعهم — بيكتشف تلقائياً إنه مشروع Vite.

## بنية المشروع — وشو بيعمل كل ملف

هاد الجزء الأهم إذا بدك تفهم المشروع مو بس تشغله:

| الملف | شو بيعمل |
|---|---|
| `index.html` | نقطة الدخول HTML. فيها `<div id="root">` يلي React بيحقن فيها كل الواجهة، وربط خطوط Google Fonts. |
| `src/main.tsx` | أول كود JS بيشتغل. بياخد عنصر `#root` من الـ HTML ويطلب من React يرسم مكون `App` جواه. |
| `src/App.tsx` | المكون الجذري (root component). ما فيه تصميم مباشر — بس بيرتب المكونات الثانية بالترتيب (Header, Hero, Services...). هيك لو بدك تبدّل ترتيب الأقسام، هون بس بتعدّل. |
| `src/components/*.tsx` | كل قسم بالصفحة إله ملفه الخاص (Hero, Services, Contact...). هاد اسمه "تقسيم لمكونات" — بيخليك تلاقي وتعدّل أي قسم بسرعة بدون ما تدوّر بملف طويل واحد. |
| `src/data.ts` | كل النصوص والبيانات (الخدمات، الإحصائيات، آراء الزباين) بمكان واحد منفصل عن التصميم. هيك لو بدك تبدّل خدمة أو تضيف وحدة، ما لازم تلمس كود الـ JSX. |
| `src/types.ts` | تعريف "شكل" البيانات بـ TypeScript (مثلاً `Service` لازم يكون فيه `id`, `title`, `description`...). لو نسيت حقل أو غلطت بنوعه، TypeScript بيحذّرك قبل ما تشغل الموقع. |
| `src/components/Gauge.tsx` | عنصر SVG مخصص (عقرب المؤشر) بيمثل حالة الورشة (مفتوحة الآن). هاد مثال على مكون بياخد "props" (`needleAngle`, `statusLabel`) ويرسم بناءً عليها. |
| `tailwind.config.js` | هون معرّفين ألوان وخطوط المشروع المخصصة (`asphalt`, `torque`, إلخ) بدل ما تكتب أكواد HEX بكل مكان بالكود. |
| `src/index.css` | يفعّل Tailwind (3 أسطر `@tailwind`)، وفيه شوي CSS عام (سكرول ناعم، احترام "تقليل الحركة" لذوي الحساسية للحركة). |
| `package.json` | لائحة كل الأدوات (dependencies) يلي المشروع محتاجها، ومختصرات الأوامر متل `npm run dev`. |
| `vite.config.ts` | إعدادات أداة البناء Vite — هاي يلي بتشغّل السيرفر المحلي وتبني نسخة الإنتاج. |
| `tsconfig.json` | إعدادات TypeScript — قد شو بدك يكون صارم بفحص الأخطاء. |

## أسئلة لازم تعرف تجاوب عنها (لفهم حقيقي، مو حفظ)

- ليش فصلنا `data.ts` عن المكونات (components)؟
- شو الفرق بين `App.tsx` والمكونات الثانية؟
- إذا بدك تضيف خدمة سابعة، وين بالضبط بتروح وتعدّل؟
- شو بيصير لو غيّرت قيمة `needleAngle` بـ `Hero.tsx` من `-45` لـ `45`؟
- ليش `Gauge.tsx` مكون منفصل مو مكتوب جوا `Hero.tsx` مباشرة؟

## خطوات قبل التسليم

1. بدّل رقم الواتساب وحساب الانستغرام والعنوان بمعلومات حقيقية (بملفات `Header.tsx`, `Hero.tsx`, `Contact.tsx`).
2. بدّل صور `Gallery.tsx` (حالياً مربعات مكانية placeholder) بصور حقيقية.
3. جرب `npm run dev` وتأكد الموقع شغال قبل الرفع لـ GitHub.
